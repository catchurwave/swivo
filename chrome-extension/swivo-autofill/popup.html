Swivo Autofill

Pré-remplit les formulaires Guichet unique

Aide

1. Depuis l'admin Swivo → dossier → bouton « Copier dans le presse-papier ».
2. Cliquez ici sur « Coller un dossier JSON ».
3. Allez sur procedures.inpi.fr ou formalites.entreprises.gouv.fr, puis « Remplir cette page ».
Les valeurs sont mappées par name, id, aria-label ou texte du label.
